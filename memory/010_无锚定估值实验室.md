# 010 无锚定估值实验室

## 职责与硬门禁

010 在不读取任何价格锚的前提下，把最新 008 规则矩阵转成估值参数、动态安全边际和五模型三情景内在价值。

创建草稿前必须同时满足：

- 固定 8 个 Profile 均存在运行。
- 每个 Profile 的最新一次运行状态必须为 success；不能用更早成功记录绕过最新失败。
- 每个最新运行必须恰好包含该 Profile 定义的 4 条规则，ID 与顺序完全一致，状态属于五状态集合。
- 存在一个最新有效 Memo；Memo 只作为叙事上下文，不要求覆盖 8 人，也不要求与 008 来源完全一致。
- 财务估值输入满足既有模型门槛。

门禁失败会一次列出缺失、失败、规则不完整或非法状态问题，不创建草稿。

## 价格盲区

010 的输入快照递归删除当前价、历史价、市值、估值倍数、评级、目标价、持仓成本、市场情绪、安全边际和交易动作。模型建议与结构化输出再次递归校验；发现价格锚即整次失败，不做降级。

当前价格只允许在 011 读取。

## 五状态与分析师权重

状态分：

| pass | neutral | unknown | warn | fail |
| ---: | ---: | ---: | ---: | ---: |
| 1.0 | 0.0 | -0.1 | -0.5 | -2.0 |

分析师原始权重：

Wraw = 0.5 × clamp(data_confidence, 0.2, 1.0) + 0.5 × clamp(profile_fit_score, 0.2, 1.0)

审计用基础权重先按 Wraw 归一化。实际差异化权重使用平方：

Wi = Wraw_i² / Σ Wraw_j²

8 位分析师都进入归一化。权重、原始权重、基础权重和平方后的中间值均写入草稿预览；确认后冻结到结果快照。

## 维度聚合

每条规则到某维度的分子贡献：

C = status_score × mapping_coefficient × analyst_weight

某维度分数：

D = ΣC / Σ(analyst_weight × abs(mapping_coefficient))

分母包含映射到该维度的所有状态，包括 neutral 与 unknown；因此 neutral 会占据证据权重但贡献 0，unknown 会贡献 -0.1 对应的负值。维度分数截断在 -2.0 到 1.0。

13 维随后聚合为 quality_score、growth_score、risk_score、分歧度、unknown_ratio 和 data_gap_penalty，再通过 valuation_models 的固定系数生成增长率、所有者收益增长率、折现率、永续增长率和情景宽度调整。

分析师对上述估值参数增量的统一放大倍数 `valuation_models.analyst_impact_scale` 默认由 `1.5` 调整为 `2.0`。该倍数作用于 `delta_growth`、`delta_owner_growth`、`delta_discount`、`delta_terminal` 以及场景宽度中的分析师增量，不直接乘最终估值结果；参数边界裁剪仍在放大后执行。

## 动态安全边际

动态安全边际完全属于 010。五状态单条加点：

| pass | neutral | unknown | warn | fail |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 0.009 | 0.012 | 0.016 | 0.03 |

每条规则贡献：

margin_contribution = status_addition × analyst_weight × 8

32 条贡献先求和得到原始动态安全边际。系统从当前五状态策略自动推导原始理论最小值和最大值，再把原始结果线性投影到 10%-50%。当前加点策略的原始理论区间为 0%-96%，所以公式为：

```text
final_margin = 10% + clamp(raw_margin / 96%, 0, 1) × 40%
```

原始累计贡献继续保留在逐规则审计中，不改变既有五状态加点。在 8 人等权且 32 条同一状态时，最终动态安全边际为：

- 全 neutral：原始 28.8%，最终 22%
- 全 unknown：原始 38.4%，最终 26%
- 全 warn：原始 51.2%，最终约 31.33%
- 全 fail：原始 96%，最终 50%

## 财务基准正常化

010 的收入、净利润、扣非净利润、自由现金流、分红和所有者盈余必须尽量使用同一来源期间。`base_net_profit`、`base_deducted_net_profit` 和 `owner_earnings_base` 不能直接取最新中报或单季值。

### 期间选择

1. 最新期为中报或季报，且具备上一完整年度、当前累计期和上年同期累计期时，按以下公式构造共同 TTM：

```text
TTM = 上一完整年度 + 本年最新累计期 - 上年同期累计期
```

2. 最新期为完整年报，或 TTM 所需组件不完整时，取最近三个同时具备净利润和 FCF 的完整年度，按配置 `valuation_models.normalization_year_weights` 的 `50%/30%/20%` 加权。
3. 只有两年时使用 `62.5%/37.5%`；只有一年时使用最近完整年度并将置信度降为低。
4. 没有完整年度且无法构造 TTM 时，不使用未年度化中报或季报，相关基数为缺失，模型返回 `needs_input`。

现金流、净利润和所有者盈余的年度权重来自同一配置键；配置只定义规则，不写入任何公司的动态增长结果。

### 所有者盈余

所有者盈余按每一个共同来源期间先计算，再做年度加权，禁止用加权净利润配单一年度资本开支：

```text
OE_y = NP_y + D&A_y - TotalCapex_y - max(-WorkingCapitalCashEffect_y, 0)
OE_base = Σ(OE_y × normalized_weight_y)
```

`TotalCapex` 作为保守的维持性资本开支代理。缺少净利润或资本开支时 `owner_earnings_base` 缺失；基数非正时所有者盈余模型不强行输出估值。

### FCF 现金转化审计

DCF 使用正常化 FCF，而不是单季度或单中报自由现金流。FCF/净利润必须使用同一来源期间、同一正常化净利润：

```text
fcf_ratio_before_cap = normalized_fcf / normalized_net_profit
fcf_cap = normalized_net_profit × fcf_profit_cap
normalized_fcf_after_cap = min(normalized_fcf, fcf_cap)
fcf_ratio_after_cap = normalized_fcf_after_cap / normalized_net_profit
```

当 FCF/净利润低于 `fcf_profit_weak` 时只降低置信度并告警；超过 `fcf_profit_cap` 时记录上限前后金额、匹配净利润、来源期间和调整记录。

### 增长基准链路

财务原始增长率按配置优先级选择：

```text
FCF CAGR 5y -> FCF CAGR 3y -> 净利润 CAGR 5y -> 净利润 CAGR 3y
-> 收入 CAGR 5y -> 收入 CAGR 3y -> default_growth
```

先得到 `raw_growth_rate`，再按 `financial_growth_min/max` 裁剪为 `clamped_financial_base_growth_rate`；008 分析师矩阵的 `delta_growth` 和 `delta_owner_growth` 在此之后分别加入并按模型边界裁剪：

```text
final_cash_flow_growth = clamp(clamped_financial_base_growth + analyst_delta_growth)
final_owner_growth = clamp(clamped_financial_base_growth + analyst_delta_owner_growth)
```

010 草稿和估值输入审计保存原始值、来源键、优先级、裁剪边界、财务基准值、两项分析师增量和两个最终基准增长率。

## 五种估值模型

默认模型权重为：所有者盈余 `35%`、DCF `35%`、剩余收益 `15%`、分红折现 `10%`、资产价值 `5%`。用户确认前可以在前端修改五个权重，合计必须为 `100%`；缺失模型会从可用模型中按已确认权重重新分配。

### DCF

```text
FCF_t = normalized_FCF_base × (1 + cash_flow_growth)^t
TerminalValue = FCF_n × (1 + terminal_growth) / (discount_rate - terminal_growth)
DCF_equity_value = Σ[FCF_t / (1 + discount_rate)^t]
                  + TerminalValue / (1 + discount_rate)^n
                  + cash_and_equivalents - interest_bearing_debt
```

DCF 使用共享正常化 FCF；折现率必须高于永续增长率至少 `discount_terminal_gap`。

### 所有者盈余

```text
OE_y = NP_y + D&A_y - TotalCapex_y - max(-WorkingCapitalCashEffect_y, 0)
OE_base = Σ(OE_y × normalized_weight_y)
```

将 `OE_base` 代入与 DCF 相同的现金流折现结构，并加现金减有息负债。公开报表无法区分维持性和扩张性资本开支，因此暂把全部资本开支作为保守代理。

### 剩余收益

```text
ResidualIncome_t = normalized_NP_base × (1 + owner_growth)^t
                   - cost_of_equity × beginning_book_equity
RI_equity_value = beginning_book_equity
                  + Σ[ResidualIncome_t / (1 + cost_of_equity)^t]
                  + PV(terminal_residual_income)
```

该模型不再额外加现金或减债，避免股东权益口径与资产负债调整重复计算。

### 分红折现

```text
Dividend_t = normalized_dividend_base × (1 + owner_growth)^t
TerminalValue = Dividend_n × (1 + terminal_growth) / (discount_rate - terminal_growth)
DDM_equity_value = Σ[Dividend_t / (1 + discount_rate)^t]
                  + TerminalValue / (1 + discount_rate)^n
```

分红是股东现金流，因此不再额外加现金或减有息负债。年度分红必须来自共享 TTM 或完整年度口径，不能把一次分红直接当成全年分红。

### 资产价值

```text
NonCashAssets = max(total_assets - cash_and_equivalents, 0)
AssetValue = cash_and_equivalents
           + NonCashAssets × scenario_haircut
           - total_liabilities
```

非现金资产折扣默认为保守 `60%`、中性 `80%`、乐观 `100%`；缺少总资产或总负债时才按配置的股东权益折扣兜底。
