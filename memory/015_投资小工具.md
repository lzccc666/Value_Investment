# 015 投资小工具

## 模块边界

015 是独立的一级模块，不属于 004-011 研究主链路，不占用研究步骤编号，也不改变 010 无锚定估值、011 价格对照或投资决策的计算与数据所有权。首版只包含持仓组合估值和 A/H/美三市场波动率温度；不包含账户同步、收益归因、自动交易、券商接入或图片资产。

持仓事实是某个持仓人在特定披露/统计日期持有某一条 `SecurityListing` 的证券数量。金额、总市值和权重均按最新可用行情与汇率即时派生，不能作为用户维护字段。ADS 数量直接乘 ADS 市价，不使用 `underlying_shares_per_listing_unit` 做额外换算。

## 数据模型

schema v9 包含 `PortfolioOwner`、`PortfolioSnapshot`、`PortfolioHolding`、`MarketFearSnapshot` 和 `BuyMemoEntry`。组合持仓在同一 snapshot 内以 `listing_id` 唯一，数量使用 `NUMERIC(28, 8)` 十进制定点字段并限制最多 8 位小数；不同统计日期保存为不同快照。持仓人和快照分别使用持久化 `display_order` 保存目录顺序。买入备忘录按选定 011 版本冻结公司/Listing、币种、中性内在价值、建议买入价、生效安全边际、最新报告期和版本号；来源外键删除时置空，快照值不变。

## API

已实现 `/api/investment-tools` 下的持仓人、快照和持仓 CRUD，支持从同一持仓人的历史快照复制持仓；组合估值为只读派生响应，批量行情刷新返回逐 Listing 和逐 FX 方向结果。`PUT /portfolio-owners/reorder` 与 `PUT /portfolio-owners/{owner_id}/snapshots/reorder` 持久化完整目录顺序，缺失、越权或重复 ID 均明确拒绝。`GET /portfolio-listings/search?q=` 只返回 015 可录入的启用中 A/H/美普通股或 ADS Listing，并按代码、名称、别名和显式市场词相关性排序。quantity、日期、币种和 Listing 均由 Pydantic 与服务层共同校验，重复 Listing 与持仓人依赖删除返回明确 `409`。`GET /market-fear` 读取三市场最近成功缓存，`POST /market-fear/refresh` 可刷新全部市场或通过 `market` 刷新单一市场。

## 行情和汇率计算规则

组合详情读取各 Listing 最新可用 `MarketSnapshot`；本地市值为 `quantity × price`，基准币种市值为本地市值乘适用 FX，权重分母只包括已计价持仓。数量、价格、汇率、市值和权重计算全部使用 `Decimal`；旧行情/FX 的 Float 在读取边界通过 `Decimal(str(value))` 转换，不把缺失值当作 0。组合行情刷新复用现有 Listing 行情与 ECB FX 服务，对 Listing 和币种方向分别去重，单项失败隔离后立即返回重新估值结果。

## 恐慌指数来源

- 美股：Cboe 官方 `VIX_History.csv` 历史日线。
- 港股：恒生指数公司官方 `01050.00/chart.json` 的 `indexLevels-3y` VHSI 日线。
- A 股：固定 AKShare `index_option_50etf_qvix()` 提供的 50ETF QVIX，前端固定标注“第三方代理指标，非官方统一恐慌指数”。

三者均按最新日频收盘值展示，不称为实时数据。服务统一计算最新值减前收、最近 20 个有效收盘均值，以及过去 3 年中不高于最新值的观测比例；该百分位直接映射为 0-100 温度，跨市场不比较绝对指数值。分段为 `<20` 平静、`<40` 稳定、`<60` 升温、`<80` 恐慌、其余极度恐慌。

## 缺失及过期数据策略

缺失行情或 FX 的持仓标记为“未计价”，不进入已计价总市值与比例分母，并显示估值不完整和未计价数量。恐慌指标抓取失败时保留最近一次成功缓存并强制标记过期、返回本次错误；没有成功缓存时返回明确不可用状态。正常读取时，抓取时间超过 36 小时或数据日期超过 7 个自然日也标记过期；成功刷新同一数据日期会更新缓存抓取时间。禁止随机值和静默空响应。
