## 核心职责

这个模块负责“公司主数据入口”和“单家公司档案入口”。

- 提供本地公司池搜索和列表展示。搜索范围来自本地 SQLite 中的 `Company` 主数据，不是联网搜索。
- 提供手动新增公司主数据的入口。当前搜索页在没有选中公司时固定显示“新增公司”表单；列表里没有的公司需要先通过该表单写入本地公司池。
- 提供公司档案页入口。基础档案展示公司简介、上市日期、东八区档案更新时间，以及公司档案展示用的实时基本信息：市值、价格、TTM市盈率、动态市盈率、静态市盈率、市净率、市销率、TTM股息率。用户从公司列表或新增成功结果进入单家公司工作台，后续财务、公告、外部证据、分析视角等模块都以 `company_id` 作为上下文。
- 提供公司基础档案更新入口。用户在公司档案页点击“更新”时，后端刷新缺失上市日期、公司简介和市场快照，并把结果写回本地公司主数据。
- 维护前端当前视图状态。当前没有使用显式路由库，`App.tsx` 用 `activeView` 和 `selectedCompanyId` 在 Dashboard、公司搜索页、公司档案页之间切换。
- 处理失效公司入口。公司档案读取返回 `Company not found` 时，前端清空当前选中公司并回到公司搜索页。

004 的职责边界只到公司身份、公司基础档案、档案页市场快照展示和进入单家公司工作台；财务同步、公告同步、外部证据搜索、分析视角生成是后续模块挂在公司档案页上的功能，不属于 004 的核心职责。市场快照只用于档案展示，不作为内在价值估值或分析师视角的默认输入。

## 对外接口（API/合约）

### 数据结构：`CompanyCreate`

`POST /api/companies` 的请求体。

```json
{
  "ticker": "600519.SH",
  "exchange": "SSE",
  "name": "贵州茅台",
  "industry": "白酒",
  "description": "A股白酒公司。",
  "listed_date": "2001-08-27",
  "status": "未研究",
  "tags": ["A股", "白酒", "消费"]
}
```

字段合约：

- `ticker`：必填，字符串，长度 1-32。证券代码，建议使用 `600519.SH`、`00700.HK`、`AAPL.US` 这类带市场后缀的唯一代码。
- `exchange`：必填，字符串，长度 1-32。交易所，例如 `SSE`、`SZSE`、`HKEX`、`NASDAQ`、`NYSE`。
- `name`：必填，字符串，长度 1-255。公司名称。
- `industry`：可选，字符串或 `null`，最长 120。所属行业。
- `description`：可选，字符串或 `null`。公司简介或研究备注。
- `listed_date`：可选，日期字符串或 `null`，格式 `YYYY-MM-DD`。
- `status`：可选，字符串，最长 40，默认 `未研究`。研究状态。
- `tags`：可选，字符串数组，默认 `[]`。标签会参与搜索。

字段合约：

- `listed_date`：日期字符串或 `null`。

- `tags`：字符串数组。
- `market_cap`：数字或 `null`，总市值，单位元。
- `current_price`：数字或 `null`，最新价。
- `pe_ttm`：数字或 `null`，TTM 市盈率。
- `pe_dynamic`：数字或 `null`，动态市盈率。
- `pe_static`：数字或 `null`，静态市盈率。

- `market_data_source_url`：字符串或 `null`。

### `GET /api/companies`

公司列表和本地搜索。

请求参数：

- `q`：可选字符串。按 `ticker`、`name`、`exchange`、`industry`、`description`、`tags` 模糊搜索。
- `limit`：可选整数，范围 1-100，默认 20。
- `offset`：可选整数，最小 0，默认 0。

响应结构：`CompanyListResponse`

```json
{
  "items": [/* CompanyRead[] */],
  "total": 1,
  "limit": 20,
  "offset": 0
}
```

字段含义：

- `items`：`CompanyRead[]`，当前页公司列表。
- `total`：整数，符合当前搜索条件的总数。
- `limit`：整数，本次分页大小。
- `offset`：整数，本次分页偏移。

### `POST /api/companies`

手动新增公司主数据。

请求体：`CompanyCreate`

成功响应：

- HTTP `201`
- 返回 `CompanyRead`

错误响应：

- HTTP `409`：同一个 `ticker + exchange` 已存在。
- HTTP `422`：请求字段校验失败。

去重规则：

- 以后端规范化后的 `ticker.upper() + exchange.upper()` 为唯一身份。
- 数据库层也有 `ticker + exchange` 唯一约束。

### `GET /api/companies/{company_id}`

读取单家公司基础档案。

路径参数：

- `company_id`：整数，本地公司 ID。

成功响应：

- HTTP `200`
- 返回 `CompanyRead`

错误响应：

- HTTP `404`：公司不存在，`detail` 为 `Company not found`。

额外行为：

- 如果公司 `listed_date` 为空，后端会尝试通过东方财富公司概况数据源补齐上市日期；补齐失败不会阻塞公司档案读取。
- 如果公司 `description` 为空，或者仍然是“真实公司主数据种子 / 不包含实时行情或投资建议”这类占位文案，后端会尝试通过东方财富公司概况数据源补齐真实简介；补齐失败不会阻塞公司档案读取。

### `POST /api/companies/{company_id}/profile/refresh`

刷新公司基础档案展示数据。

路径参数：

- `company_id`：整数，本地公司 ID。

成功响应：

- HTTP `200`
- 返回更新后的 `CompanyRead`

刷新行为：

- 如果 `listed_date` 为空，先尝试通过东方财富公司概况补齐上市日期。
- 如果 `description` 为空或仍是占位文案，先尝试通过东方财富公司概况补齐真实简介。
- 通过东方财富行情快照刷新 `market_cap`、`current_price`、`pe_ttm`、`pe_dynamic`、`pe_static`、`pb_ratio`、`ps_ratio`、`market_data_source`、`market_data_source_url`、`market_data_updated_at`。行情主接口不可用时使用 `push2delay.eastmoney.com` 备用接口。
- 通过东方财富 F10 分红融资数据计算 `dividend_yield_ttm` 和 `dividend_yield_static`。
- 外部源某一项指标缺失时，对应字段保持 `null`，前端显示“待更新”。

错误响应：

- HTTP `400`：证券代码暂不支持行情快照刷新。
- HTTP `404`：公司不存在，`detail` 为 `Company not found`。
- HTTP `502`：外部行情源请求失败或返回不可用数据。

### 前端接口合约

`frontend/src/services/api.ts` 暴露给 004 使用的函数：

- `getCompanies(params)`：调用 `GET /api/companies`。
  - 入参：`{ q?: string; limit?: number; offset?: number; signal?: AbortSignal }`
  - 返回：`Promise<CompanyListResponse>`
- `createCompany(payload)`：调用 `POST /api/companies`。
  - 入参：`NewCompanyPayload`
  - 返回：`Promise<Company>`
- `getCompany(companyId, signal?)`：调用 `GET /api/companies/{company_id}`。
  - 入参：`companyId: number`
  - 返回：`Promise<Company>`
- `refreshCompanyProfile(companyId)`：调用 `POST /api/companies/{company_id}/profile/refresh`。
  - 入参：`companyId: number`
  - 返回：`Promise<Company>`

`CompanySearchView` 对父组件的合约：

- `selectedCompanyId: number | null`：当前是否已选中公司；为 `null` 时显示固定“新增公司”表单。
- `onSelectCompany(companyId: number): void`：选择列表公司或新建成功后进入公司档案。
- `refreshToken: number`：外部刷新信号，变化时重取公司列表。

`CompanyWorkspaceView` 对父组件的合约：

- `companyId: number | null`：当前公司档案上下文。
- `onBackToSearch(): void`：返回公司搜索页。
- `onCompanyUnavailable(): void`：公司不存在时清空选中状态并回到搜索页。
- `refreshToken: number`：外部刷新信号，变化时重新加载档案数据。
- 组件内“更新”按钮会调用 `refreshCompanyProfile`，成功后只替换当前 `company` 对象，不重置已加载的财务、公告、证据和分析数据。
