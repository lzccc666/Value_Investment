# 004_公司搜索与公司档案页

## 本轮目标

把 `GET /api/companies` 接到前端，补出公司搜索页、公司列表页和公司档案页入口，让用户能从搜索进入单家公司工作台。

## 已完成

### 后端

- 新增公司详情读取接口 `GET /api/companies/{company_id}`。
- 保持列表接口 `GET /api/companies` 的分页和搜索参数不变。
- 补充公司接口测试：
  - 公司列表返回种子数据
  - 关键字过滤
  - 公司详情读取

### 前端

- 新增前端 API client：
  - `getCompanies`
  - `getCompany`
- 将应用拆成三个视图：
  - `DashboardView`
  - `CompanySearchView`
  - `CompanyWorkspaceView`
- 公司搜索页支持：
  - 关键词搜索
  - 列表展示
  - 空状态、加载态、错误态
  - 进入公司档案入口
- 公司档案页支持：
  - 按 `company_id` 读取详情
  - 展示基础资料、标签、研究入口
  - 返回搜索页
- 保留 Dashboard 作为首页，但公司搜索已经是实际可用入口。

## 设计思路

- 这轮没有上正式路由库，先用本地视图状态完成闭环，减少改动面。
- 公司搜索和公司档案都直接依赖后端真实接口，不再用静态占位数据。
- 档案页先做“入口”和“骨架”，后续 005/006/007 可以顺着它接财务、公告和分析模块。
