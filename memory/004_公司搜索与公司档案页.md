# 004_公司搜索与公司档案页

## 模块职责

004 是研究主链路入口，负责公司池、证券身份、公司档案、行情快照和工作区选择状态。财务、公告、证据、分析、Memo、估值和价格决策均以 `company_id` 为根。

## 当前能力

- 按名称、代码、行业和标签搜索公司。
- 分页读取本地公司池。
- 同名多地上市公司按 A 股 > 港股 > 美股排序，默认优先展示境内主记录。
- 新增公司并校验 `ticker + exchange` 唯一性。
- 读取公司详情；种子描述或上市日期缺失时可按当前规则补全。
- 主动刷新公司档案、当前价格、市值、总股本和行情更新时间。
- A 股行情通过东方财富适配器获取，并提供延迟接口回退。
- 前端保存完整 `Company` 作为当前研究对象，Dashboard 展示“公司名 + 代码”。
- 公司被删除或不可访问时，工作区清除选择并返回搜索页。

## API

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| `GET` | `/api/companies` | 搜索与分页 |
| `POST` | `/api/companies` | 新增公司 |
| `GET` | `/api/companies/{company_id}` | 公司详情 |
| `POST` | `/api/companies/{company_id}/profile/refresh` | 刷新档案与行情 |

列表参数包括 `query`、`limit` 和 `offset`。新增公司最少需要 `ticker`、`exchange`、`name`，其余档案字段可选。

## Company 关键字段

- 身份：`id`、`ticker`、`exchange`、`name`
- 档案：`industry`、`description`、`listed_date`、`status`、`tags`
- 行情：`current_price`、`market_cap`、`total_shares`
- 来源：`profile_source`、`market_data_source`、`market_data_updated_at`
- 时间：`created_at`、`updated_at`

## 前端行为

- Company Search 提供搜索、分页、新增和“档案”入口。
- 从公司档案返回搜索时恢复进入前的搜索词、分页和页面滚动位置。
- Company Workspace 顶部展示公司身份与基础资料，内部有 8 个 section。
- Dashboard 最近公司行可直接选择公司并进入 Overview。
- 未选择公司时点击研究模块会引导到公司搜索。
- 可选子模块请求失败不会让基础档案页面整体崩溃。

## 当前限制

- 公司档案和行情适配主要覆盖东方财富可识别证券，跨市场字段完整度不同。
- 跨市场优先级目前基于同名公司和交易所排序；历史名称、别名及不同语言名称尚未建立统一发行人映射。
- 行情是研究快照，不是交易级实时行情。
- 公司基础资料缺少完整的行业分类、管理层、业务分部和历史名称体系。
