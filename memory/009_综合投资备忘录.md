# 009 综合投资备忘录

## 职责与边界

009 将多个 008 结果整理为投资委员会叙事。它只做来源选择、事实归并、共识与分歧、风险、反方证据、数据缺口、待复核估值假设和来源映射。

009 不计算规则分、分析师总分、加权分、权重、评分卡或动态安全边际；不输出旧 valuation_signal_pack 或 parameter_impacts；不读取当前价，也不产生买卖、持有、加减仓或仓位建议。

## 来源门槛

- 按 Profile 选择最新成功的 008 运行。
- 当前来源集合只允许固定 8 个 Profile；退役 Profile 的历史 run 和旧 Memo 原样保留，但不进入新的 009 来源快照、准备区成功名单或风险/缺口汇总。
- 生成 Memo 至少需要 2 个成功 Profile，默认值来自 memo_decision.min_successful_analysts。
- 缺失或最近失败的 Profile 会进入委员会账本的 missing_profiles，供叙事说明。
- 009 不要求 8 人齐全；8 人齐全且每人规则完整是 010 的独立门禁。

## 确定性委员会账本

后端在调用模型前确定：

- source_run_ids 及成功、缺失 Profile。
- shared_evidence_ids、shared_announcement_ids、financial_periods。
- consensus_candidates 与 dissent_candidates。
- critical_risk_candidates、data_gap_candidates。
- valuation_assumption_queue。

账本只从选中的 008 快照和真实来源引用构建。模型不能新增不存在的运行、Evidence、公告或财务期间引用。

## Memo 输出合同

InvestmentMemoOutput 只允许以下叙事字段：

- title、research_conclusion、executive_summary。
- core_thesis、consensus_points、dissent_points。
- business_quality、financial_quality、management_and_capital_allocation、moat_and_growth。
- key_risks、counter_evidence、data_gaps、follow_up_questions。
- valuation_assumption_queue、watch_signals。
- source_map、confidence_summary。
- 固定 price_decision_status=not_started 与禁止交易动作说明。

Pydantic 使用 extra=forbid。analyst_scorecard、total_score、weighted_score、rule_score、suggested_safety_margin、valuation_signal_pack 等旧数值字段会直接导致模型输出校验失败。

## 严格价格盲区

009 在两处执行递归控制：

1. 构建来源快照时删除所有价格锚字段并清洗嵌套文本。
2. 模型输出解析后递归扫描所有字段与字符串；发现当前价、历史价、市值、估值倍数、评级、目标价、持仓成本、市场情绪、安全边际或交易动作即使运行失败。

固定的 prohibited_actions_note 与 price_decision_status 只用于声明边界，不作为研究结论参与扫描。

## 持久化与历史

每次成功生成：

- 保存一条 run_type=investment_memo 的 AnalysisRun。
- 保存一条 InvestmentMemo 版本，包含 sections、markdown、source_analyst_run_ids、source_snapshot_hash 和配置快照。
- 新版本成为 latest，旧版本继续保留，可归档或软删除。
- 历史 Memo、历史分析、历史估值和历史价格决策不会因迁移或新版本而被物理删除。

## 与 010 的关系

010 需要一个最新有效 Memo 作为叙事上下文并固定 memo_id。该 Memo：

- 不需要覆盖全部 8 个分析师。
- 不要求 source_analyst_run_ids 与 010 当前读取的 8 个最新 008 完全一致。
- 不提供任何数值评分或安全边际。

010 自己重新读取 8 个 Profile 的最新一次 008 运行，执行完整门禁和数值聚合。这样 009 的叙事职责与 010 的可复现计算职责相互独立。

## 前端

公司工作区的 009 区域按固定 Profile 顺序展示当前 8 人的来源覆盖、共识、分歧、风险、反方证据、数据缺口、待复核假设与 Memo 历史。界面不展示退役 Profile、分析师评分卡、总分、加权规则分或动态安全边际。
