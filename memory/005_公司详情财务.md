# 005_公司详情财务

## 模块职责

005 负责把外部财务报表转换为可审计的本地底稿和确定性财务证据包。它是 008 分析师视角和 010 估值实验室的主要量化输入，但不直接输出投资结论。

## 当前数据范围

东方财富财务适配器同步四类记录：

1. `main_indicator`：主要财务指标
2. `income_statement`：利润表
3. `cash_flow`：现金流量表
4. `balance_sheet`：资产负债表

前端最多展示 60 个报告期，并按报告期折叠，同期内按固定报表顺序展示。008 的分析快照选择最近 40 个报告期，010 再从证据包中选择适合估值的年度或 TTM 口径。

## API

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| `GET` | `/api/companies/{company_id}/financials` | 分页读取财务底稿 |
| `GET` | `/api/companies/{company_id}/financials/evidence-pack` | 生成本地财务证据包 |
| `POST` | `/api/companies/{company_id}/financials/sync` | 同步外部财务数据 |
| `DELETE` | `/api/companies/{company_id}/financials/{statement_id}` | 删除指定财务记录 |

财务列表支持 `period_limit` 和 `period_offset`，限制的是报告期而不是单条报表。

## FinancialStatement

关键字段：

- 标识：`id`、`company_id`、`statement_type`、`period`、`report_date`
- 来源：`source`、`source_record_id`、`currency`
- 结构化数据：`data`
- 原始与追踪：`raw_snapshot`、`created_at`、`updated_at`

同步按公司、报表类型、报告期和来源标识去重，可创建新记录或覆盖已有记录。

## 财务证据包

`financial_evidence_pack` 由后端确定性构建，主要包括：

- `facts`：收入、利润、现金流、资产负债和每股类事实
- `financial_metrics`：盈利能力、增长、现金流、资本结构和股东回报指标
- `trends`：按报告期排列的关键序列
- `flags`：利润表质量、现金流覆盖、资产负债和会计口径风险
- `gaps`：估值与分析所需字段缺口及严重度
- `cash_flow_quality` 与 `cash_flow_coverage`
- `balance_sheet_adjustments`
- `capital_allocation`
- `valuation_readiness`
- `quality_matrix`、`analyst_summary` 和 `data_quality`

证据包保留来源记录 ID 和报告期，供后续分析引用。缺失字段以 gap 表示，不使用猜测值静默补齐。

## 关键口径

- 自由现金流优先使用经营现金流减资本开支的标准化结果。
- 经营现金流/收入比例按比率存储和展示，避免百分数重复换算。
- 利润表字段用于补齐营业收入、营业成本、营业利润、利润总额、所得税和净利润等事实。
- 资产负债表汇总现金、总债务、净现金、权益和有形资产相关字段。
- 同期不同报表可以互补，但每个事实都保留来源类型和记录 ID。

## 前端行为

- 支持同步、报告期搜索、折叠展开和单条删除。
- 显示报表类型、报告期、来源和记录 ID。
- 展示证据包摘要、关键指标、趋势、质量提示和缺口。
- 财务旗标和数据缺口不只显示数量，也展示具体明细，便于用户直接理解风险提示和缺失字段。
- 删除失败时保留当前记录并显示可操作错误。

## 当前限制

- 回购金额、严格投入资本和严格 ROIC 仍可能缺失。
- 维持性资本开支无法从公开报表直接可靠区分。
- 不同市场和行业的报表字段差异会降低证据包覆盖度。
- 非经常性损益、分部数据和会计政策变更仍需结合公告人工复核。
