# 011 价格对照与投资决策

## 职责

011 是研究链路中唯一允许读取当前价格的阶段。它绑定一条已经确认完成的 010 ValuationRun 及该估值固定关联的 Memo，读取 010 冻结的 dynamic_safety_margin，再生成买入参考价和价格状态。

011 不重新读取 008，不读取 Memo 评分，不计算分析师分数，不重算动态安全边际，也不管理资金、持仓或组合。

## 输入门槛

- ValuationRun 必须属于目标公司且状态为 completed。
- ValuationRun 必须有可用的三情景内在价值。
- ValuationRun 必须绑定有效 Memo。
- ValuationRun.results.dynamic_safety_margin 必须存在且位于 10%-50%。
- 当前价格必须为正数并保存为 PriceSnapshot。
- 用户覆盖值可空；非空时范围为 10%-50%。

默认选择该公司最新完成的 010，但 API 可显式指定 valuation_run_id。新 009 Memo 不会改变既有 010 的 memo_id 或既有 011。

## 安全边际

- suggested_safety_margin：直接读取绑定 010 的冻结动态安全边际。
- safety_margin_override：用户可选覆盖值。
- effective_safety_margin：有覆盖时取覆盖，否则取建议值。
- 买入价：intrinsic_value × (1 - effective_safety_margin)。

建议值、覆盖值、生效值、010 公式版本和来源快照分别保存，历史可复现。前端输入以百分比展示，允许 10%-50%。配置变化不改写既有 010 或 011；绑定的旧 010 建议值不在当前范围内时，需要重新生成 010 后再创建新的价格决策。

## 价格状态

以配置的参考情景内在价值和买入价为边界：

1. current_price <= suggested_buy_price：达到目标安全边际。
2. current_price < base_intrinsic_value：低于内在价值但安全边际不足。
3. current_price == base_intrinsic_value：接近内在价值。
4. current_price > base_intrinsic_value：高于内在价值。

三情景分别保存 intrinsic_value、buy_price 和相对当前价的安全边际。比较边界固定互斥。

## API 输出

公开 API 返回：

- valuation_run_id、memo_id、price_snapshot_id。
- current_price、currency、price_as_of。
- conservative/base/optimistic 内在价值与买入价。
- suggested_safety_margin、safety_margin_override、effective_safety_margin。
- reference_scenario、suggested_buy_price、current_margin_of_safety、price_status。
- 来源与配置快照元数据。

API 和前端不返回 analyst_score_total 或 analyst_scorecard。数据库中的同名旧列只为兼容已有历史表结构，允许空值；新记录不伪造 0 分。

## 历史与不可变性

每次生成创建新的 PriceDecisionRun。旧价格决策、旧价格快照、绑定估值与 Memo 均保留；配置发布、008 修改、009 重生成或新 010 都不会原地改写历史 011。

## 前端

011 区域展示绑定估值、当前价格、建议安全边际、10%-50% 覆盖输入、三情景买入价、当前安全边际和价格状态。不展示分析师评分卡或综合分。
